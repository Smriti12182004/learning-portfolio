# Week 2 – Deep Thinking Questions & Explorations

This document contains deeper questions explored while working with Data Processing and Exploratory Data Analysis.

---

### Question:1

Two datasets can have the same mean value, but can their behavior be completely different?

### Exploration:

Yes. Mean only represents the central value but does not describe:

- Data spread
- Distribution shape
- Presence of outliers

### Learning:

A complete understanding of data requires:

- Mean
- Median
- Standard deviation
- Distribution visualization

---

### Question:2

If statistical values look correct, do we still need visualization?

### Exploration:

Yes. Numerical summaries may hide:

- Unexpected patterns
- Clusters
- Extreme values
- Non-linear relationships

### Learning:

Visualization acts as a validation step before making decisions.

---

### Question:3

Should every extreme value be deleted?

### Exploration:

Not always.

An outlier can represent:

- Measurement error
- Rare event
- Important observation

### Learning:

Outliers should be investigated before removal.

---

### Question:4

Can different analysts reach different conclusions from the same data?

### Exploration:

Yes, because analysis depends on:

- Questions being asked
- Features selected
- Visualization techniques
- Assumptions made

### Learning:

Data analysis combines technical skills with decision-making.

---

# Final Reflection

The biggest learning from Week 2 was understanding that data analysis is not only about executing Python commands.

The real challenge is:

- Asking the right questions
- Understanding data behavior
- Selecting appropriate methods
- Converting observations into meaningful insights
