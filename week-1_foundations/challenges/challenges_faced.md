# Challenges Faced

## 1. Testing on Multiple CSV Files
The tool needed to work correctly on different CSV structures.

Solution:
Created and tested another CSV file to verify row count, column detection, missing values, and numeric statistics.


## 2. Adding --top N Feature
Initially, the tool only generated basic profiling output.

Solution:
Implemented the --top N command-line option using argparse to display the most frequent values in text columns.


## 3. File Recovery and Project Organization
Some project files/screenshots were accidentally removed during development.

Solution:
Used Git status and VS Code Local History to identify and recover previous versions.
